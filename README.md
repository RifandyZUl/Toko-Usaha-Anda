# Toko Usaha Anda

Landing page modern dan responsif untuk toko yang menyediakan alat rumah tangga, perkakas tukang, dan alat motor dengan kualitas terbaik.

## Fitur

- **Design Modern** - Desain minimalis dengan gaya Nike, fokus pada whitespace dan typography yang kuat
- **Fully Responsive** - Optimal di semua device (mobile, tablet, desktop)
- **Performance** - Fast loading dengan optimasi gambar dan lazy loading
- **User Experience** - Smooth scrolling, animasi halus, dan interaksi yang intuitif
- **Google Maps Integration** - Integrasi lokasi toko dengan Google Maps
- **Contact Form** - Form kontak dengan validasi lengkap

## Tech Stack

- **React 18** - UI Library
- **Vite** - Build tool yang cepat
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Icon library
- **React Router** - Routing

## Instalasi

```bash
# Install dependencies
cd frontend/landing
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Design Features

- **Nike-style Design** - Minimalis, clean, dengan fokus pada produk
- **Color Scheme** - Black & white theme yang elegan
- **Typography** - Montserrat untuk heading, Inter untuk body, Lobster untuk logo
- **Responsive Grid** - Layout yang adaptif di semua ukuran layar
- **Smooth Animations** - Transisi dan animasi yang halus

## Sections

1. **Hero Section** - Section utama dengan CTA yang jelas
2. **Product Categories** - Kategori produk dengan layout alternating
3. **Featured Products** - Produk unggulan dengan variasi aspect ratio
4. **About** - Informasi tentang toko dan statistik
5. **CTA** - Call to action section
6. **Contact** - Form kontak dan informasi kontak
7. **Footer** - Footer dengan Google Maps integration
